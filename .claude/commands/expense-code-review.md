Perform a thorough, general code review of feature $ARGUMENTS

## Outputs
The output of this command should be a file named "/docs/reviews/feature-YYYY-MM-DD.md" with at least the following categories

1. SOLID priciple violations
2. Security concerns (e.g. advisories on libraries, issues impacting the OWASP top 10)
3. Complex code
4. Undocumented code
5. Code without unit test coverage
6. Recommendations
