# Document Feature
- Creates documentation the feature $ARGUMENTS

## Input
Analyze code that is related to the $ARGUMENTS feature. These could be both frontend or backend files.

## Outputs
For the given feature, create the following documents:
1. Developer Documentation: Create an MD file with useful information for developers. Highlight if the changes are to the frontend, backend or fullstack. Name the file docs/dev/{feature-name}.md
2. User Documentation: Create a document suitable for public visibility in a file called docs/user/{feature-name}.md. Include screenshots to demonstrate key functionality.
