Assist new developers get oriented with this application.
If specified, developers can deep dive into more detail in $ARGUMENTS

The output of the command should be an "orientation.md" file in the /docs dir of the project.

The documentation should contain:
1. A high level overview of the entire application
2. General architecture 
3. Flow of data
4. How to run the application locally
5. Other relevant information to help onboard a developer
